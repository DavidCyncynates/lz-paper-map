# Review manifests

Successful scans that find a new or revised paper, along with targeted manual
corrections, add a small JSON manifest here. The manifest records the public
arXiv pages inspected, proposed record changes, citation evidence, and validation
results so that every change remains auditable. New manifests also record
whether discovery coverage completed and summarize each required listing,
search, citation-neighbor, and author lane. A targeted correction or incomplete
scan may not advance the catalog timestamp. No manifest is added for a clean
no-change run.
